# Lumen Drift

夜の海図に浮かぶ「ルーメン」を集め、消えかけた灯台を再点灯する、見下ろし型3Dアクション・プロトタイプです。紫の嵐に触れず、制限時間内に必要な光を回収してください。

## 特徴

- Three.jsだけで描画する、サーバー不要の静的ブラウザゲーム
- すぐに遊べるタイトル、成功・失敗、リスタートのゲームループ
- 発光する結晶、回転する嵐、星図のような海面による独自のビジュアル
- ステージ、敵、移動速度、制限時間をデータから調整できる構造

## 技術・必要環境

- HTML5 / CSS3 / JavaScript（ES Modules）
- [Vite](https://vite.dev/)
- [Three.js](https://threejs.org/)
- Node.js 20 以降、npm

## インストールと起動

```bash
npm install
npm run dev
```

表示されたローカルURLをブラウザで開きます。

## 操作方法

- **WASD** または **矢印キー**: 航行する
- **航行を開始 / もう一度航行**: ゲーム開始・リスタート

ルーメンを6個集めれば成功です。嵐の輪に触れるか、60秒が経過すると失敗になります。

## 開発とビルド

`src/game/config.js` は試作の調整点です。必要数、ルーメンや嵐の配置、プレイヤー速度、時間をここで変更できます。

```bash
npm run build
```

本番用の静的ファイルは `dist/` に生成されます。確認には `npm run preview` を使用できます。

## GitHub Pages への公開

1. `npm run build` で `dist/` を生成します。
2. `dist/` の内容をPages公開用ブランチ（例: `gh-pages`）に配置します。
3. GitHubの **Settings → Pages** でそのブランチと `/(root)` を公開元に選びます。

Viteの相対パス設定により、リポジトリ配下のGitHub Pagesでもそのまま読み込めます。

## ディレクトリ構成

```text
src/
├─ game/       # 実行制御と調整可能なゲームデータ
├─ entities/   # プレイヤー、収集物、障害物
├─ systems/    # 入力などの横断システム
├─ ui/         # HTML UIの状態表示
└─ world/      # ステージの3D環境
```

## 今後追加できる機能

- `config.js`にステージ定義を追加するステージ選択
- 新しい障害物・収集アイテムと能力差のある航行者
- サウンド、タッチ操作、スコア記録
- 難易度や視覚テーマの切り替え
